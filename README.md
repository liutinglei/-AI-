# 小热·山水有声
### Xiaore Living Heritage

> 让历史有形，让山水有声。

## 每一座城，都藏着一部还没有讲完的史诗

山水记得道路，建筑记得时代，器物记得曾经相逢的人。真正动人的旅行，是在风景之外，重新听见这些沉默的记忆。

我们想象未来的一天：孩子在湖边向小热追问一座亭阁的来历，远方的游客在数字展厅接续同一个篇章，离开的人又在书签、杯子与随身物件中认出那一段故事。一次旅行由此拥有了前奏、相遇和余音；一座城的文化，也获得可以不断续写的表达。

小热是一位面向文旅叙事的数字角色。棕色卷发、青绿山形头箍、宫殿胸饰与云水衣纹，构成它的识别线索。项目从承德的山水园林与文化交流意象出发，探索连接公开史料、连续故事、AI数字人和三维文创的方法。

## Evidence to Epic · 有据叙事

```text
公开史料 → 事实锚点 → 叙事单元 → 数字人讲述 → 空间反馈 → 文创转译
               └──── 同一份可追溯叙事包 ────┘
```

一个叙事包同时保存事实与出处、角色表达、表演线索、追问入口和物件意象，使同一文化线索能在网页、数字屏幕、三维角色和实体设计中复用。创新落在这份连接上：让文化拥有亲近的声音，让技术成为人与历史之间的桥梁。

## 当前原型

- 三个原创故事章节：山水、时间、相逢；事实摘要关联公开来源。
- 可运行的离线叙事引擎与有限主题追问，以及独立的可选模型接口。
- 彩色分件、真实网格与三场景总览，共10个 Blender 工程。
- 八款三维文创：立像、钥匙扣、徽章、纪念牌、杯子、帆布袋、书签和手机支架。
- 包含角色、模型渲染、三维预览与愿景画面的本地展示网页。

2026-10-13 已在 Blender 4.5.14 LTS 中重新打开公开总览工程，并成功渲染彩色、真实网格与文创三个场景，未发现缺失贴图。首批源码、图片和模型包已完成本地整理，正在准备发布；本仓库当前先公开项目故事，下载包与在线展厅尚未上线。

## 从一个角色，到一张文化星图

远期愿景是开放的地域叙事网络：不同地方维护自己的史料与角色，不同创作者续写各自的篇章，同一套可追溯结构把独立的文化记忆连接起来。小热可以是第一位同行者，后来还会有更多具有地域气质的讲述者。

下一阶段计划探索骨骼与口型表演、多语种讲述、经授权的现场叙事与跨地域共创。这些是未来方向；当前版本尚未实现实时数字人驱动、空间部署或实物制造验证，也没有已验证的商业效果。

## 公开史料

故事样例的事实锚点依据 [UNESCO 世界遗产中心的承德遗产条目](https://whc.unesco.org/en/list/703/)。项目使用精简事实摘要与原创叙述，不代表相关机构的认可或背书。
